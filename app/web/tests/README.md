# Синтетическая проверка frontend

Из корня checkout, с установленными зависимостями проекта и FFmpeg в PATH:

```powershell
python app/web/tests/serve.py --port 8768
```

Стенд слушает только `127.0.0.1`. Он создаёт геометрическое тестовое видео на CPU;
модель и GPU не запускаются. Не используйте здесь банковские материалы.

- `http://127.0.0.1:8768/tests/browser.html` — кнопка «Запустить проверки»:
  API-моки, ошибки, гонки запросов, JPEG, видео, модальное окно и адаптивность.
- `http://127.0.0.1:8768/tests/event-feed.html` — кнопка «Запустить»:
  20 синтетических событий на ширинах 1440, 1024 и 390 px; выбор №5 и последнего
  события, длинное описание и источник, seek без сдвига страницы, одна открытая
  карточка, границы навигации, сброс результата.
- `http://127.0.0.1:8768/tests/preview.html?view=upload` — просмотр загрузки;
  `?view=result`, `?view=clean`, `?view=failed` — остальные состояния.
- Для ленты из 12 событий откройте `/`, включите «Деморежим», выберите
  «Лента — 12 синтетических событий», нажмите «Тестовый файл» и «Начать проверку».

Остановка стенда — `Ctrl+C` в его терминале. Ключ не требуется в деморежиме;
реальный режим по умолчанию сохранён. Тестовые панели не отображаются в обычном
интерфейсе. Демо не подтверждает работу реального inference.

При проверке этой версии 18.10.2026 браузерный набор дал **45 PASS / 0 FAIL**,
дополнительные проверки ленты — **3 PASS / 0 FAIL**. Проверены также Enter,
сворачивание доступа и возврат к вводу отсутствующего ключа. Проверенный вариант
перенесён из локальной копии Argon с совпадением SHA256 файлов; скриншоты и
локальные материалы Cline в коммит не входят.
