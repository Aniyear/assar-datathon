| API URL | `https://rearview-vaporizer-celestial.ngrok-free.dev/api/v1/analyze` | Это endpoint загрузки POST; проверить публичный API перед отправкой |
| API Key | Действующий ключ production из локального защищённого файла | Вставить непосредственно в предназначенное поле формы; не в Git, URL или переписку с AI |
| Presentation | Финальная презентация в формате/по ссылке, которые принимает форма | По подтверждению пользователя готовит Омар; финальная готовность и доступность ещё не подтверждены |

Polling: `GET https://rearview-vaporizer-celestial.ngrok-free.dev/api/v1/jobs/{job_id}`.
Оба API-метода требуют `X-API-Key`. Если подсказка поля формы требует базовый API URL,
указать origin с `/api/v1` и отдельно дать оба маршрута; не утверждать, что формат
этого поля известен из пересказа. Не указывать localhost или URL тестовой страницы.

## Перед отправкой

1. Зафиксировать принятую сборку и честные ограничения по результатам локальной
   приёмки. Два принятых правила не означают покрытие всех нарушений кейса.
2. После отдельного разрешения опубликовать через штатный launcher. Проверить
   интерфейс, ключ, POST/polling и повторный GET с другой сети; JSON вместо страницы
   предупреждения туннеля. Сетевой стенд сам по себе этого не доказывает.
3. Проверить репозиторий и презентацию в приватном окне без авторизации. Проверка
   GitHub REST без токена 18.10.2026 вернула 404 для существующего origin:
   **публичный доступ не подтверждён**. Видимость в этом проходе не менялась.
   Перед открытием репозитория проверить всю публикуемую историю/ветки на данные и
   секреты; одной проверки текущего `.gitignore` недостаточно.
   В доступной локальной истории проверены 739 записей путей: запрещённых корней,
   имён видео/весов/SQLite и стандартных файлов ключей не найдено. Это проверка
   имён, **не полный аудит содержимого на секреты** и не подтверждение публичности.
4. Омар сверяет почту и имя команды с регистрацией, вставляет ключ локально в форму
   и отправляет. Сохранить подтверждение сдачи локально, без скриншота с ключом.
5. Указать реальное окно доступности и контакт. Ноутбук остаётся с питанием, без сна
   и конкурирующего GPU-прогона; после проверки жюри — штатная остановка.
