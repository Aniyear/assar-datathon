# assar — пакет передачи жюри

**Подготовленный черновик. Сервис не опубликован, финальная приёмка не пройдена.**
Это документация и примеры формата, а не подтверждение доступности сервиса.
Финальный commit, URL, окно доступности и решение о выпуске заполняются после
исправлений ML и проверки конкретной сборки. API-ключ в пакет не входит.

Команда: Омар Масалимов (капитан), Анияр Байбосын (интеграция и сервис).

логи, веса, локальные пути к датасету и секреты в него не входят. Код доступен
в репозитории команды по конкретному commit; архив не содержит runtime/весов.

## Сборка пакета без GPU и публикации

Из корня integration checkout:

```powershell
& '..\..\.venv\Scripts\python.exe' scripts/prepare_jury_package.py
```

Скрипт не запускает API, модель, браузер или туннель. Создаёт новый архив
`outputs/jury/assar-jury-draft-<UTC timestamp>.zip` и SHA256-квитанцию рядом.
Всегда маркирует его `draft_not_for_submission`: успешная упаковка не является
приёмкой. После изменения ML пересобрать пакет и обновить измерения; не отправлять
черновик с незаполненным шаблоном как финальный результат.

## Проверка подготовки пакета — 18.10.2026

```powershell
& '..\..\.venv\Scripts\python.exe' -m pytest tests/integration/test_jury_package.py tests/integration/test_service_operations.py tests/integration/test_ngrok_support.py -q --tb=short
# 34 passed in 6.55s; CPU, синтетический localhost, внешние туннели не запускались.
```

Синтаксис пяти операционных PowerShell-примеров проверен без выполнения команд;
новая строка pytest выше является записью фактически выполненной проверки.
Архив проверен по CRC и SHA256 каждого файла; ссылки на дополнительные документы
ведут к точному source commit, локальные ссылки разрешаются внутри пакета.
Для 22 зависимостей найдены 24 LICENSE/NOTICE-файла, отсутствующих нет.
Это не новая полная проверка inference: ML, API, контракт, frontend, модель,
каталог и readiness в этом проходе не менялись. Полный CPU/GPU-suite повторно
не запускался. Приёмка сборки остаётся непройденной; пакет не заменяет решение
о выпуске.
