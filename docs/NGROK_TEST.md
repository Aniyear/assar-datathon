## Воспроизведение

Пользователь установил ngrok по [официальной инструкции Windows](https://ngrok.com/download/windows)
через Microsoft Store и самостоятельно выполнил `ngrok config add-authtoken`.
Токен в чат не передавался. При настройке нового аккаунта команду с токеном вводить
только локально; перед ней в PowerShell можно отключить сохранение истории:
`Set-PSReadLineOption -HistorySaveStyle SaveNothing`. Для текущего аккаунта повторять
настройку не нужно. MCP и платная подписка для этого теста не нужны.

того же адреса. При занятом endpoint или ошибке смотреть только `tunnel_error_codes`
в `outputs/service/network-test/state.json`; не публиковать исходный вывод агента
или конфигурацию с токеном. Остановка касается только процессов этого launcher.

## Ограничения и защита

- [Бесплатный план](https://ngrok.com/docs/pricing-limits/free-plan-limits) выдаёт один
  dev-домен аккаунту; выбирать красивое имя бесплатно нельзя. На момент проверки:
  1 ГБ исходящего трафика и 20 000 HTTP-запросов в месяц. Эти лимиты существенны для
  будущих JPEG; текущий маленький сетевой тест не измеряет ёмкость сервиса с видео.
- При первом входе браузер может показать страницу ngrok: нажать **Visit Site**.
  Автопроверка использует `ngrok-skip-browser-warning`; её успех не доказывает
  отсутствие этой страницы. Пользователь отдельно подтвердил страницу через
  мобильный интернет при отключённом Wi-Fi. API с ключом на телефоне не проверялся.
- Локальный inspector отключён `--inspect=false` и `web_addr=false`; remote management
  и автопроверка обновлений выключены. Исходный stdout/stderr ngrok не сохраняется:
  фильтр оставляет только допустимый публичный origin и `ERR_NGROK_<номер>`.
  Это защита локальных журналов, не заявление об отсутствии обработки на стороне ngrok.
  [Параметры агента v3](https://ngrok.com/docs/gateway/agent/config/v3).
- Токен не включается в argv; переменные `NGROK_*` не наследуются процессом тестового
  туннеля. Тестовый API-ключ отличается от production. Все секреты/бинарники/квитанции
  находятся в ignored `outputs`, не в Git. Редиректы HTTP с ключом запрещены.
- Тестовый сервер не принимает загрузки, не отдаёт файлы и не вызывает модель.
  `--ngrok` разрешён только с `--mode network-test`. HTTPS проходит через
  инфраструктуру ngrok; этот тест не является разрешением передавать банковские
  материалы через неё. Финальная публикация и согласование канала остаются отдельным шагом.
