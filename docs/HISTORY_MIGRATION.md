обновление README и эта карта — изменения документации, не новый GPU-прогон.

## Для Омара и остальных локальных копий

Не выполняйте обычный pull/merge старой и новой истории: это вернёт прежние
коммиты в опубликованную ветку. Сохраните старую папку, локальные данные и
незакоммиченные изменения. Самый простой вариант — новая папка рядом:

```powershell
git clone --branch codex/ml https://github.com/Aniyear/assar-datathon.git assar-ml-updated
```

Для продуктовой сборки клонируйте main:

```powershell
git clone https://github.com/Aniyear/assar-datathon.git assar-release
```

Эти команды не переносят веса, данные, ключи и локальный model.local.json.
Старую рабочую папку не удалять. Если в ней есть новая работа, сначала отдельно
проверить diff и перенести только необходимые изменения поверх новой базы;
не вливать целиком старую ветку. Не присылайте приватные артефакты в Git.

Прочие существующие worktree на машине интегратора оставлены на прежних локальных
refs с неизменёнными файлами. Обновлённые remote-tracking refs отражают GitHub;
локальные старые ветки сохраняются для безопасной синхронизации их владельцами.
Три локальных экспериментальных коммита отдельного потока в продукт не включены.

Работающий сервис не перезапускался: его run receipt по-прежнему указывает
исходный commit запуска. Файлы runtime не изменены. Для следующего запуска
достаточно START.cmd в существующей integration-папке.
