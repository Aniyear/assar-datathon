документации и истории, а не повторная приёмка модели или новый GPU-прогон.

## Обязательно использовать свежие клоны

Из старых клонов **не делать push и не объединять их историю с новой**.
Один merge старой ветки вернёт удалённые сведения. Сохраните незакоммиченные
изменения и приватные артефакты локально; переносите только проверенные правки
поверх новой базы. Старые папки и резервные копии не публикуйте.

Для продукта:

```powershell
git clone https://github.com/Aniyear/assar-datathon.git assar-release-clean
```

Для ML:

```powershell
git clone --branch ml https://github.com/Aniyear/assar-datathon.git assar-ml-clean
```

Веса, данные, ключи, SQLite и local-config не входят в Git и не переносятся
этими командами. Работающий сервис не требуется останавливать для очистки Git.
Переход запуска на новую папку выполняется отдельно и штатно, с сохранением
ключа и результатов; две копии сервиса на GPU одновременно не запускаются.

Актуальные ветки: main, integration-cpu, ml, backend, bootstrap, frontend,
finish-plans, experiment-2b4b-3060. Разработка продукта продолжается только
на свежей копии integration-cpu; исходные архивные клоны не являются базой
для новых коммитов. Авторы новых коммитов — Aniyear и omqrm.
