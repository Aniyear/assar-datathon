# Запуск assar двойным кликом

Откройте папку существующей сборки:
`C:\Users\aniya\Рабочий стол\assar-datathon\.worktrees\integration-cpu`.

- **START.cmd** — запустить сервис, модель и публичный ngrok. Проверки готовности,
  SHA256 и занятости GPU выполняет штатный launcher. Дождитесь `PRODUCTION HTTPS`.
- **STATUS.cmd** — показать состояние и текущий адрес, не раскрывая ключ.
- **STOP.cmd** — штатно остановить сервис, его модель и туннель. Результаты и ключ сохраняются.

Запуск не требует ввода длинных команд или прав администратора. START.cmd явно
публикует сервис; оставьте его окно открытым. При повторном клике во время свежего
активного запуска второй процесс не создаётся; показанный адрес остаётся прежним.
Если запущен только локальный режим, сначала STOP.cmd, затем START.cmd.

Пути разрешаются относительно самих файлов, а не текущей папки терминала.
Используется уже подготовленный `outputs/service/production/model.local.json` и
закреплённый `outputs/tools/ngrok/ngrok.exe`; веса и токен не скачиваются.
На другом компьютере сначала подготовить окружение и эти локальные файлы по
[отчёту приёмки](ACCEPTANCE_6CA5_3060.md). Перенос одного START.cmd вне папки проекта
не работает; можно создать обычный Windows-ярлык на него.

Ключ: `outputs/service/production/private/api-key.txt`. Скопировать непосредственно
в интерфейс или форму жюри. В Git, команды, чат и журналы ключ не добавляется.
Адрес при текущем аккаунте: https://rearview-vaporizer-celestial.ngrok-free.dev/ .
При предупреждении ngrok нажмите Visit Site. Ноутбук должен оставаться с питанием,
интернетом, без сна и конкурирующего GPU-процесса. Автозапуск после перезагрузки
не установлен: нужно снова открыть START.cmd.
