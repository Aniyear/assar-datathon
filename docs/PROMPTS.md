# Промпты для параллельной реализации assar

**Архив первоначальных заданий.** По решению пользователя 17.10.2026 продукт целиком
ведёт один Codex в `codex/integration-cpu`, ML — один Claude Омара в `codex/ml`.
Не запускать новых frontend/backend/GPU-писателей по промптам ниже. Текущие
границы: [AGENTS.md](../AGENTS.md), [BRANCH_MAP.md](BRANCH_MAP.md) и
[финальный план](01_CURRENT_STATE_AND_FINISH_PLAN.md). Старые сроки/роли сохранены
только как история; действующий API и ML-интерфейс не меняются от смены владельца.

Это задания для **следующего этапа**. Текущий этап — анализ и планирование. Отправка промпта координатору ниже означает начало реализации. Сначала вставляйте общий контекст, затем одно задание роли. В новом чате приложите только перечисленные документы проекта, без исходных видео, кадров и их описаний.

У Анияра Codex/ChatGPT Pro и Gemini Pro (Gemini 4 Argon); у Омара Claude Pro. Анияр с Codex ведёт интеграцию, оценку и развёртывание на своей RTX 3060 Laptop 6 GB, а с Argon — фронтенд. Омар с Claude ведёт backend и ML в отдельных чатах/рабочих папках, ручную разметку train/dev и обучение на рабочем сервер; его ноутбук — RTX 3050 4 GB. Для публичных норм Анияр использует отдельный исследовательский чат Gemini. Участники работают на разных компьютерах в отдельных ветках. Возможность агентной работы зависит от установленного клиента и доступа аккаунта, а не только наличия модели в веб-чате.
