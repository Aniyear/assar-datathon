# assar

Локальный сервис анализа кассовых видео для кейса **ForteBank Datathon 2026**.
Команда: **Анияр Байбосын (Aniyear)** и **Омар Масалимов (omqrm), капитан**.

Сервис принимает MOV, показывает ход проверки и возвращает `violation` или
`no_violation`. Для найденных событий доступны таймкоды, 1–3 JPEG-доказательства
и нормативное обоснование с оговорками. Невыполнимый анализ получает `failed`.

**Состояние на 18 октября 2026:** локальная техническая приёмка на RTX 3060 Laptop
6 ГБ пройдена; сервис опубликован через ngrok. Это MVP с двумя правилами,
а не система полного покрытия всех нарушений кейса.

## Открыть сервис

- **Веб-интерфейс:** https://rearview-vaporizer-celestial.ngrok-free.dev/
- **API base URL:** https://rearview-vaporizer-celestial.ngrok-free.dev/api/v1
- Ключ передаётся жюри отдельно и не публикуется в репозитории.

При первом открытии ngrok может показать предупреждение — нажмите **Visit Site**.
Сервис доступен, пока ноутбук команды включён, подключён к интернету и запущен
туннель. Публикация не означает круглосуточный хостинг или гарантию доступности.
Внешний UI/API проверены: 17/17 HTTP-проверок; пользователь подтвердил открытие
интерфейса через мобильный интернет. Проверка мобильного API с ключом отдельно
не выполнялась. Сетевая проверка использовала только синтетический MOV.

## Запуск на подготовленном ноутбуке

В папке сборки откройте двойным кликом:

| Файл | Действие |
|---|---|
| [START.cmd](START.cmd) | Проверка окружения, запуск модели, сервиса и публичного ngrok |
| [STATUS.cmd](STATUS.cmd) | Состояние и текущий адрес без вывода ключа |
| [STOP.cmd](STOP.cmd) | Штатная остановка собственных процессов и туннеля |

Дождитесь `PRODUCTION HTTPS` и оставьте окно запуска открытым. Повторный клик
во время активного запуска не создаёт вторую модель. Результаты и ключ
сохраняются после штатной остановки. После перезагрузки нужен новый запуск.
[Короткая инструкция](docs/QUICK_START.md).

Локальный ключ находится в `outputs/service/production/private/api-key.txt`.
Его можно скопировать непосредственно в интерфейс; нельзя
добавлять в Git, URL, скриншоты или журналы.

## Подготовка другой машины

Нужны Windows, Python 3.11, FFmpeg/ffprobe в PATH, совместимый NVIDIA-драйвер
и локальные веса/runtime. Итоговая конфигурация проверена на RTX 3060 Laptop
с 6144 MiB VRAM; работоспособность на другом оборудовании требует своей проверки.

```powershell
git clone https://github.com/Aniyear/assar-datathon.git
cd assar-datathon
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
```

Веса, runtime, ключи и локальные настройки в Git не входят. Подготовьте
`outputs/service/production/model.local.json` с фактическими путями к файлам,
сохранив параметры и SHA256 из [configs/model.yaml](configs/model.yaml).
Порядок и проверенные пути описаны в [отчёте приёмки](docs/ACCEPTANCE_6CA5_3060.md).
Для внешнего доступа также нужны закреплённый ngrok в `outputs/tools/ngrok/ngrok.exe`
и локальная авторизация аккаунта: [настройка ngrok](docs/NGROK_TEST.md).
Не переносите чужие токены и не меняйте readiness ради запуска.

Без публикации сервис можно запустить отдельно:

```powershell
.\scripts\assar.ps1 start --model-config .\outputs\service\production\model.local.json --port 8000
```

## HTTP API

Оба метода требуют заголовок `X-API-Key`.

| Метод и путь | Назначение |
|---|---|
| `POST /api/v1/analyze` | Multipart/form-data, поле `file`, файл MOV; HTTP 202 и `job_id` |
| `GET /api/v1/jobs/{job_id}` | Получить `processing`, `done` или `failed` |

В `done` находятся `verdict` и список `violations`. Каждое событие содержит тип,
описание со ссылкой на источник, таймкод и JPEG в base64. `failed` не означает
отсутствие нарушения. Без ключа или с неверным ключом API возвращает 401.
При занятости единственного рабочего процесса — 503; ожидающей очереди GPU нет.
Лимит загрузки — 100 MiB, общий бюджет обработки — 300 секунд.

[Инструкция для жюри](docs/jury/GUIDE.md) · [OpenAPI](docs/jury/openapi.json) ·
[Контракт](docs/CONTRACTS.md).
В документах старта сохранены исторические состояния; текущая конфигурация
и итоговый отчёт приёмки имеют приоритет при выборе команды запуска.

## Модель и устройство

- **Qwen3-VL-4B-Instruct-GGUF Q4_K_M**, визуальный проектор **Q8_0**.
- **llama.cpp b11669**, локальный `llama-server`; промпт `cash-specialists-v6`,
  `max_tokens=500`. Версии, SHA256 и остальные параметры закреплены в конфигурации.
- Backend: FastAPI, supervisor, один изолированный worker и SQLite.
- Frontend: HTML/CSS/JavaScript, локальный просмотр видео и лента событий
  с одной открытой карточкой.
- Supervisor переиспользует собственный сервер модели между заданиями,
  останавливает его при зависании и выполняет ограниченное восстановление.
  JPEG сохраняются в результате после очистки временных файлов задания.

Inference выполняется на машине команды, без облачных моделей. Анализ только
визуальный: звук и распознавание лиц не используются. Публичный доступ проходит
через ngrok; это транспорт к локальному сервису, а не внешняя модель.

## Покрытие и ограничения

Активны только **MULTI-01** и **CASH-03**, подтверждённые капитаном.
**MULTI-01 — предположение о возможном нарушении:** источник не устанавливает
прямого запрета на само присутствие нескольких клиентов. Оговорка сохраняется
в ответах. Условия, необходимые сведения и исключения:
[принятые правила](docs/ACCEPTED_RULES_V6.md).

Пропуск обязательной проверки из-за нехватки времени не превращается в
`no_violation`: без подтверждённого события будет `failed`, с подтверждённым
событием — `violation` с ограничением полноты. Технические ошибки остаются `failed`.
Успешная обработка не гарантирует правильность наблюдений или юридического вывода.

относятся к типам вне каталога; в метрике они остаются пропусками. Dev использовался
при настройке, поэтому это не независимая оценка качества. Frozen test не использован.

Подтверждены реальные `done` и JPEG, завершённые обязательные проверки отрицательных
ответов, повторное задание, timeout/recovery и сохранение результата после перезапуска.

**5781 MiB максимальный снятый показатель**, **1073 MiB после**; это периодические
снимки с учётом рабочего стола, а не непрерывное измерение пика памяти модели.

CPU: полный набор — **347 passed** до последней правки launcher; итоговые

## Данные и разработка

Видео, кадры, аннотации, ответы модели, SQLite, веса и секреты остаются локально
и исключены из Git. Не прикрепляйте их к issue/PR и не передавайте облачным моделям.
Данные жюри не используются для обучения. Разделение train/dev/frozen-test
зафиксировано по группам дубликатов; X-4/X-47 относятся к одной группе только dev.
[Правила split](docs/DATA_SPLIT.md).

`main` содержит принятую сборку; разработка продукта ведётся в `integration-cpu`,
модели — в `ml`. Экспериментальные ветки не являются готовым релизом.
[Порядок синхронизации Git](docs/HISTORY_MIGRATION.md).

Для разработки и CPU-проверок из корня checkout:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m pytest tests/integration --runxfail -q
.\.venv\Scripts\python.exe scripts/check_bootstrap.py
```

На машине команды общий Python может находиться в `..\..\.venv`; скрипты запуска
выбирают его автоматически. GPU-проверки выполняются отдельно на свободной карте.
