[Правила агентов](AGENTS.md) задают владельцев общих файлов и границы данных. [Нормативные кандидаты](docs/normative_candidates.md) требуют проверки действующей редакции и применимости; они пока не являются активным каталогом модели.

## Проверить стартовую основу

CPython **3.11**, FFmpeg/ffprobe — отдельно для будущего сервиса. В PowerShell из корня:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.lock
.\.venv\Scripts\python.exe -m pip check
.\.venv\Scripts\python.exe scripts/check_bootstrap.py
.\.venv\Scripts\python.exe -m pytest -q
```

Это CPU-проверки контрактов/настроек и синтетического split, без модели и датасета.
Реальный приватный freeze на машине Анияра дополнительно проверяется командой:

```powershell
.\.venv\Scripts\python.exe scripts/data/freeze_split.py validate
```

`requirements.in` задаёт прямые версии; `requirements.lock` фиксирует все транзитивные
зависимости и тестовый runner. [Версии и ограничения окружения](docs/DEPENDENCIES.md).
PyTorch/CUDA/Transformers добавляются интегратором после handoff Омара и замеров.

Для Argon: [пять синтетических JSON](tests/fixtures/contracts/README.md), `docs/CONTRACTS.md`
и frontend-промпт. Базовая проверка не запускает HTTP-сервис. После реализации backend
Омар передаст точный импорт ASGI-приложения; рекомендуемый entrypoint — `app.api.main:app`:

```powershell
# Только после появления backend и настройки реальной модели/проверенных правил:
$env:ASSAR_API_KEY = (& .\.venv\Scripts\python.exe -c "import secrets; print(secrets.token_urlsafe(32))")
.\.venv\Scripts\python.exe -m uvicorn app.api.main:app --host 127.0.0.1 --port 8000 --workers 1
```

Не запускать несколько ASGI/GPU workers и `--reload` на сдаче. Ключ создаётся локально
без вывода в чат. `.env.example` описывает настройки, `.env` автоматически не читается.
Backend вызывает `configure_offline_environment()` до импорта ML, проверяет готовность
весов и каталога. Сейчас модель `not_configured`, каталог пуст; фиктивного анализа нет.

## Воспроизведение технического аудита

Нужны Python 3.10+ и FFmpeg/ffprobe в PATH либо пути к ним через параметры. Скрипт использует стандартную библиотеку Python, не обращается в сеть и не извлекает изображения для облачного анализа.

```powershell
python scripts/audit_dataset.py --archive 'C:\Users\aniya\Downloads\open.zip' --decode
```

При другом расположении архива заменить путь. Если FFmpeg не в PATH:

```powershell
python scripts/audit_dataset.py --archive 'C:\path\open.zip' --ffmpeg 'C:\ffmpeg\bin\ffmpeg.exe' --ffprobe 'C:\ffmpeg\bin\ffprobe.exe' --decode
```

Архив безопасно извлекается в `data/raw/open/`; исходные файлы не изменяются. Существующий файл с другим размером или CRC не перезаписывается. Результаты — в `analysis/local/`:

- `audit_summary.json` — итоговые числа и проблемы;
- `video_manifest.csv` и `labels_normalized.csv` — технический манифест и нормализованные метки;
- `decode_checks.json` — полное декодирование 40 уникальных видео;
- `review.html` — локальный просмотр человеком, переход к исходному таймкоду, экспорт заметок; существующая страница при повторном аудите сохраняется;
- `human_annotation_template.csv` — заготовка для ручной проверки; повторный аудит существующую заготовку не перезаписывает.

HTML хранит заметки в памяти страницы до скачивания JSON. Сохранить экспорт перед закрытием в приватную папку. Для нескольких событий добавить отдельные строки в локальную аннотацию; исходная отметка не является полным списком событий. Если MOV не проигрывается в браузере, открыть исходник локальным видеопроигрывателем.
